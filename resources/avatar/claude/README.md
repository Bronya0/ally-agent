# Claude-girl avatar

All four files (`idle.webp`, `proud.webp`, `stretch.webp`, `happy.webp`) are
derived from `characters/claude/` in
[CrossPet (lokicorvus/crosspet)](https://github.com/lokicorvus/crosspet),
revision `6e98970f6ff9b44e8ac85215241cabcd78f67d92`.

Ally processing: proportionally resized from 640px to 320px high, without
cropping; re-encoded with Sharp as WebP (quality 90, alpha quality 100, effort 6).
Transparency and a common canvas height are preserved for pose switching.
Upstream `happy-2.webp` is shipped as `happy.webp`.

Pose usage in Ally: `idle` is the resting image, `proud` and `stretch` play as
short idle actions, `happy` shows while the speech bubble is up.
