[Small-tailqwq/dsh-deep-whale](https://github.com/Small-tailqwq/dsh-deep-whale),

This is community fan art, not an official DeepSeek mascot or endorsement.
Ally processing: proportionally resized from 512x512 to 320x320, without
cropping; re-encoded with Sharp as WebP (quality 90, alpha quality 100, effort 6).
Transparency is preserved.

`sleeping.png` is the original 256×256 PNG image extracted from the same
revision's `maid-atelier/assets/icons/sleepy.ico`, retained as a source
reference. The current rest expression uses `sleeping-bust.webp` so the
silhouette stays consistent with the other expressions.

`idle-blink.webp`, `pat.webp`, `thinking.webp`, and `sleeping-bust.webp` are
AI-generated expressions derived from `delighted-320.webp`; see `PROMPTS.md`
for the exact prompts and `NOTICE.txt` for the unchanged attribution chain.
They retain the CC BY-NC-SA 4.0 artwork terms.
