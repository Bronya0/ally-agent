Ally 自带模型吗？

Ally 是连接模型与开发工具的桌面助手，需要配置你使用的模型服务，或登录已授权的 ChatGPT 账号。模型调用的费用、额度与能力取决于对应服务，Ally 可为不同工作区选择不同模型。

从原版 Ally 切换，需要重新配置吗？

Ally Native 沿用原版的 ~/.ally_agent 配置与会话数据。原生界面使用 Go 与 MyGo 绘制，常规页面、文件浏览与编辑都在原生桌面内完成。

怎么让 Ally 操作远程主机？

先添加 SSH 节点，再在当前工作区勾选授权。Ally 会从授权节点列表中选择目标，通过远程工具读写文件、执行命令和传输资源。节点支持本机免密、私钥与密码认证。

macOS 首次打开被拦截，怎么办？

应用使用 ad-hoc 签名且未做公证。确认安装包来自项目的 GitHub Releases 后，在「系统设置 → 隐私与安全性」中选择「仍要打开」。DMG 中将 Ally.app 拖入「应用程序」后再启动。
