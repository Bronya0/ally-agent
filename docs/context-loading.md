# 工作区上下文加载清单

“设置 → 通用 → 上下文加载”提供可选来源开关，默认全部开启。内置工具开关已从 MCP 页迁入，默认折叠；离开设置时走统一保存事务。MCP 页只管理 MCP 服务器和对端工具。

## 主对话默认加载

“默认加载”指实际发起模型请求时构建上下文，不是打开工作区就把文件内容全部送给模型。以下来源有内容或满足条件时才附带正文；用户档案、项目教训即使没有正文，也可能保留用途和维护说明。

| 加载项 | 内容与来源 | 当前边界 |
| --- | --- | --- |
| 内置系统提示词 | Ally 身份、工具约定、编辑纪律、输出风格、协作策略、安全规则等 | 固定基础规则 |
| 平台与执行环境 | 系统、架构、Python 探测信息、shell 名称及路径、路径格式和执行约定 | 内置提示词的一部分；不是任意环境变量或密钥 |
| 用户级项目指令 | `~/.agents/AGENTS.md`，不存在或无有效内容时尝试 `agents.md` | 先于工作区指令拼接；单文件最多注入头部 64 KiB |
| 工作区根指令 | 根目录依次尝试 `AGENTS.md`、`CLAUDE.md`、`agents.md`、`claude.md` | 只取首份有效文件，单文件头部 64 KiB |
| 一级子目录指令 | 每个一级普通、非隐藏子目录下的 `AGENTS.md` | 不是所有 Markdown；不递归更深目录，不对子目录应用 CLAUDE 回退；每份头部 64 KiB，合并目前没有统一总预算 |
| 用户档案 | 应用数据目录的 `USER.md`，默认路径显示为 `~/.ally_agent/USER.md` | 去掉 frontmatter，保留正文头部最多 8 KiB；附用途/维护说明 |
| 全局记忆索引 | 应用数据目录 `memories/` 下记忆的路径和 description | 最多 200 项，索引条目共 8 KiB，每项描述最多 300 字符；不自动加载每份记忆正文 |
| 项目教训 | 工作区根目录 `LESSONS.md` | 保留最新 100 行，再限制为尾部 16 KiB；附记录教训的规则 |
| 项目代码图谱 | 工作区根目录 `CODEGRAPH.md` | 保留头部最多 8 KiB；仅作为导航参考 |
| 自定义提示词 | 设置中的 `CustomPrompt` | 非空时附带；当前构建入口没有单独的字节预算 |
| 已启用技能元数据 | 项目、用户、额外来源和内置技能的名称、描述、适用场景 | 不预载 SKILL.md 正文；描述/适用场景分别最多 250 字符，清单不设总条数/总字节上限 |
| 工作区结构图 | 根路径、目录和文件名、大小、识别到的技术栈与关键文件名 | 不包含文件正文；深度 3、最多 320 项、每目录文件预算 50；超过 1 MiB 的文件不进入结构图 |
| 内置工具 schema | 本会话实际可用的内置工具名称、描述、参数定义 | 依据配置和可用能力筛选；与执行权限关联 |
| MCP 工具 schema | 本会话实际注入的 `mcp__...` 工具名称、描述、参数定义 | 排除禁用工具；不是服务器全部配置或凭据；上下文面板已单列其估算占用 |

用户级与工作区指令会按绝对路径去重，并标注来源。普通 `README.md`、任意子目录 Markdown、全部源码和全部记忆正文都不会因为存在就自动完整注入。

源码入口：[系统提示词](../internal/app/biz_prompt.go)、[指令与代码图谱](../internal/app/biz_project_context.go)、[工作区结构图](../internal/app/biz_workspace.go)、[工具清单](../internal/app/biz_mcp.go)。

## 条件上下文和运行数据

以下内容也占上下文，但不适合与“自动加载文件”混为一组：

- **知识库模式规则**：工作区与配置的知识库根匹配时加入，描述 index/_index、检索和 sources 只读约定；不会因此自动注入整个知识库或 index 正文。
- **会话附加工作区**：授权的额外根目录及路径约定。会话中变更时，在新用户轮次前插入变更通知。
- **历史消息**：用户提问、AI 回复、实际执行的工具调用和结果。压缩后可能包含总结或保留的计划快照；按现有裁剪、预算和持久化规则处理。
- **本轮输入及附件**：用户文本、附件说明、实际可发送给该模型的图像等；不等于把资源管理器中所有文件发送给模型。
- **按需工具结果**：read 读取的文件/记忆正文、skill 加载的技能正文与有界目录树、MCP/SSH 查询结果、网页内容等；这些在调用工具后进入历史。
- **流程控制消息**：用户中断标记、计划进度核对提醒，以及具体运行路径的重试/预算/子代理报告等。它们按运行状态出现，不是默认读取磁盘的独立资料块。
- **协议推理状态**：已捕获且供应商要求回传的 reasoning/thinking 状态按模型和协议处理，不能作为普通文件加载开关随意裁掉。

源码入口：[消息组装及快照](../internal/app/biz_context.go)、[附加工作区通知](../internal/app/biz_turn_notice.go)、[主循环](../internal/app/app.go)。

## 生效时机

- 主对话的系统提示词、技能定义、工作区结构图和工具清单在首次实际请求时形成会话快照，后续请求复用。打开上下文统计面板只预览，不应提前冻结它们。
- 保存配置或编辑文件通常影响新会话，不能据此声称已有对话已替换上下文。
- 成功压缩会通过 `refreshSessionPromptPrefix` 成套清理这些快照，后续请求重建；释放会话也清理。
- 这些快照在内存中，不保证跨关闭或重启永久冻结。
- 关闭某项自动注入，不能撤回已经进入历史的旧正文；也不自动禁止模型通过 read 按需读取它。自动加载与文件读取权限是两件事。

## 子代理与定时任务

它们不完整复用主对话前缀，后续开关必须接入各自入口：

- 子代理有自己的系统提示词、委派任务、步数预算和实际工具清单；默认加入工作区环境、深度 2/最多 60 项的文件列表、项目教训、项目指令、代码图谱和自定义提示词。
- `cleanContext` 跳过工作区环境/项目教训和代码图谱，仍保留项目指令与自定义提示词；不应把它描述为“完全无上下文”。
- 当前子代理不直接调用主对话的用户档案、全局记忆索引和技能元数据构建入口，且不获得 skill 工具。父代理提供的任务文本或后续工具结果仍可能包含相关信息。
- LLM 定时任务通过新的隔离子代理上下文执行，`CleanContext=false`，工具清单另有筛选；命令型定时任务直接执行命令，不构建 LLM 上下文。

源码入口：[子代理](../internal/app/orch_subagent.go)、[定时任务](../internal/app/orch_scheduler.go)。

## 设置边界

当前可控制这些加载项：用户级指令、根目录指令、子目录指令、用户档案、记忆索引、项目教训、代码图谱、自定义提示词、技能元数据、工作区结构图。关闭任一项都会先弹出同一份确认，说明影响范围与恢复方式，风险文案只在弹窗里维护一份，不跟着每个开关重复。重新开启不需要确认。

内置基础规则、实际工具 schema、会话消息和流程控制另行展示。工具 schema 若需要关闭，应复用现有工具启停配置，同步注入与执行权限，不再维护一套只隐藏 schema 的独立开关。

加载项与内置工具的开关选择只对新会话生效：首次请求后保留到会话释放，成功压缩不会改用后来保存的开关；文件正文仍可在压缩后按原加载选择重建。快照仅在内存中保留，重启或释放会话后重新采用当前配置。上下文面板用千位单位显示估算 token：小于 1k 保留一位小数（如 0.8k），1k 及以上用整数 k（如 26k），更大时用 M/G；并区分预加载上下文、内置工具 Schema、MCP 工具 Schema 与消息数据。
