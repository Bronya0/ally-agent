# 工具效率审查（2026-10-18）

目标：降低复杂度、减少无效往返、节省模型上下文。本文审查当前工作区版本，包含本轮已完成的 read / grep / 本地 command 优化。

覆盖 27 个内置工具的声明、分发、主要执行路径和模型侧结果处理，以及 MCP 的公共适配路径。未连接真实 SSH 主机、未调用实际 MCP 服务、未运行子代理或计划任务的付费模型调用；相应结论来自源码和合成结果探针。数字均为 UTF-8 字节数，不是 token 数，也不代表典型任务的实际用量。

## 修复结果

1. **已修复：长错误限量。** 模型侧超过预算的错误改为有界文本块，保留错误码、首尾原因与恢复信息；界面仍保留原始错误。相同 200 KB MCP 错误探针，从 204,839 字节降到 12,391 字节。短错误保持原有结构。
2. **已修复：远端命令真实首尾。** Python helper 的三个读取分支共用现有捕获容量，溢出时保留真实开头和结尾，标记省略并对齐 UTF-8。没有增加远端日志下载协议。已在本地执行大输出命令验证；未连接真实 SSH 主机。
3. **已修复：MCP 等价结果去重。** 对完整 JSON 进行保守比较，仅省略与已有内容等价的 structured output。保留补充说明、不同结果、仅结构化结果，并避免大整数精度误判。
4. **已精简：工具说明。** 去掉错误码枚举及冗长的结果格式解释，保留调用约束；错误码仍可随具体错误返回。完整 27 个声明从 50,118 字节降到 45,508 字节，顶层 description 从 19,841 降到 15,402 字节（约减少 22%）。参数结构保持一致。
5. **已修复：skill 输出。** 直接返回已有 skill-loaded 文本块，省掉 JSON 包装；目录最多 80 项、总文本约 8 KB，两层目录共享预算。正文最多 256 KB（与面板保存技能的上限同源），超限明确报错并指向源文件供 read 分段读取，不静默加载残缺指令。
6. **已修复：保留能决定下一步的元数据。** HTTP 结果增加保存路径、实际下载大小、二进制编码标记，以及 Location / Retry-After / Link / ETag / Last-Modified / WWW-Authenticate；所选响应头共享约 4 KB 预算。计划任务创建与列表结果同时给出 UTC 下次执行时间。远端 create 也接入现有精简回执。
7. **按用户要求保留：子代理完整报告。** 不新增报告预算、不裁剪摘要或文件清单；回归测试覆盖长报告原样进入父上下文。

## 逐项覆盖

| 工具 | 当前实现与审查结论 |
|---|---|
| list_files | 默认深度 3、条目 200；模型结果只保留路径，单目录也有折叠预算。保持现有协议。 |
| read | 本轮已改为每文件约 16 KB；版本、行号、续读与会话去重保留。 |
| grep | 去掉额外 20 文件分组限制，保留匹配行数和文本预算；新增约 16 KB 的路径预算（平铺重复路径也计入），裁剪后按实际展示行数续读，单条超长路径保留完整保证前进。 |
| edit | 版本校验、批次写入、精简回执、更新版本复用已具备；不重做编辑协议。 |
| create | 模型只收到创建状态、版本和摘要；校验按批次去重且默认关闭。 |
| delete | 一次可传多个路径，归一化后返回各路径结果；不存在项标记 absent，避免反复删除。 |
| command | 本轮已保存被模型裁剪的完整输出，并从日志读取真实尾部。 |
| service | start/read/stop/list 合并为一个工具；read 模型正文最多 8 KB，列表不重复带日志。tailBytes 超过 8 KB 仍会二次裁剪，属于参数说明可简化点。 |
| wait | 可取消、reason 有长度限制；同批调用延后等待，不增加查询协议。 |
| ask | 问题和选项有数量/长度上限；自动填 ID、一次呈现多问。独占调用批次是现有交互契约。 |
| scheduled_task | 列表和回执已精简；command 模式不调用 LLM，instruction 模式按计划触发子代理。本轮补齐创建/列表的下次执行时间。 |
| http_request | 请求和下载量有界，支持保存文件；本轮补齐关键元数据，见修复 6。 |
| web_fetch | 默认文本 60,000 字符、最多 80 个链接，模型正文预算 96K 字符；这是仍可能较大的输出。可用现有 maxChars 收窄；降低默认值属于信息完整性的取舍，不宜直接套 read 的预算。 |
| remote_read | 与本地共用预览和会话去重；本轮同步缩到约 16 KB，不新增远端分页结构。 |
| remote_edit | 与本地相同的单文件版本契约；已有精简回执，不重复发送 diff。 |
| remote_create_file | 本轮复用 create 的精简回执，保留创建状态、版本和摘要。生产函数不生成 diff，不将其计为大额节省。 |
| remote_delete_path | 已复用本地删除的批量结果渲染，远端 helper 批量判定后执行。 |
| remote_run_command | 本轮修复前缀截断，保留真实首尾；远端超时仍杀进程组，没有新增全量日志传输。 |
| remote_transfer | tar 原始流传输，返回路径、统计与摘要，不把文件内容作为文本回传；只存在少量重复字段。 |
| ssh_cluster | 返回已授权节点的脱敏摘要；新节点缺字段一次报全。大量节点时列表可能增长，当前不为此新增搜索/分页接口。 |
| calculate | 表达式长度、嵌套与节点数有界，结果简短；保持。 |
| screenshot | 图片最长边 1568、编码体积有上限；图片从多模态通道传入，base64 不重复进入工具正文，窗口列表也有限额。 |
| render_html | 输入上限 50,000 字符，结果只确认渲染状态/长度/标题，不回显 HTML。 |
| plan | 结果最多显示 30 步，finish 可一次推进多步；历史自然追加，不注入变化的前缀快照。 |
| subagent | 已有轮数与私有读缓存；按用户要求保留完整最终报告，不设报告预算。 |
| skill | 直接返回完整技能文本块；正文超限给出分段读取指引，附带目录共享条数/字节预算，见修复 5。 |
| suggest | 默认鼓励生成 1–4 个建议，但成功后直接结束 run，**没有额外一轮模型调用**。是否改成按需建议属于交互偏好，不列为主要节省项。 |
| MCP（动态工具） | 公共适配限制成功文本和长错误，二进制用占位说明，等价 JSON 去重，不盲目重试已执行失败的调用；未审查每个第三方服务内部实现。 |
