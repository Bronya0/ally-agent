# UI translations

Ally uses MyGo's catalogs and locale selection. The supported languages are
English (`en`), Simplified Chinese (`zh-Hans`), Japanese (`ja`) and Korean (`ko`).
English is the source and fallback language. MyGo matches the system's preferred
languages against these catalogs, remembers a manual selection, and restores
system matching when the user chooses System default.

The JSON catalogs and generated Go accessors live in `locales/`. Fixed UI text
uses `locales.Text` with its existing Chinese source text. The generated lookup
maps only known messages to catalog keys; unknown text passes through unchanged.
User content, paths, model IDs, tool names, protocol values and provider responses
remain data. Keep display labels separate from values and widget keys. MCP, API,
Token, SSH and other established technical terms need no artificial translation.

Add a `ui_…` key to all four catalogs when adding UI text. Catalog strings use ICU
escaping for literal braces and apostrophes. Existing dynamic UI messages use Go
formatting after lookup; translations use explicit argument indexes such as
`%[2]d sessions in %[1]s` when their word order differs. Preserve each argument's
type and formatting flags. MyGo's own Korean messages are `mygo.…` entries; the
Chinese and Japanese entries follow the framework translations.

After editing catalogs, regenerate and validate:

```sh
go run scripts/i18n.go
go tool mygo generate
go tool mygo i18n check
go test ./locales ./desktop ./desktop/uikit
```

Commit the catalogs and generated Go files so ordinary Go builds work offline.
Runtime translation reads embedded data, never disk or a translation service.
Fixed messages use MyGo's bounded cache and allocate nothing after the first
lookup. Derived text caches include the locale; language changes invalidate
them without changing session context, configuration IDs or unsaved input.

The catalog tests verify all four languages resolve their own messages without
fallback, literal round-tripping, printf argument compatibility and allocation
behavior. The existing desktop fixtures explicitly use Chinese; additional
regressions exercise language changes and option values.
