# md2other

## 文件位置

本技能目录下的 `md2docx.py`。技能加载时 `<skill-loaded dir="...">` 给出的路径就是本技能目录，脚本与 `SKILL.md`、`test_md2docx.py` 都在里面；用绝对路径调用，不要假设当前目录。

## 依赖

```bash
pip install python-docx
pip install pywin32          # PDF 转换需要
```

脚本的 `--pdf` 仅适用于安装了 WPS Office 和 pywin32 的 Windows（通过 COM 接口 `Kwps.Application` 调用）。macOS/Linux 不支持此路径；先生成 DOCX，再按环境使用可用的文档转换工具。安装依赖前先检查环境，并遵循用户已有授权。

## 参数

未明确说明时默认即可。

| 参数 | 必填 | 说明 |
|------|:----:|------|
| `input` | 是 | 输入 Markdown 文件路径 |
| `-o / --output` | 否 | 输出路径，默认 input.docx |
| `--cover` | 否 | 生成封面页 + 目录 |
| `--header` | 否 | 添加页眉（文档标题） |
| `--footer` | 否 | 添加页脚"第 X 页" |
| `--numbering` | 否 | 标题自动编号（检测到原文已有编号时跳过） |
| `--pdf` | 否 | 同时生成 PDF |

## 用法示例

```bash
python "<技能目录>/md2docx.py" readme.md
python "<技能目录>/md2docx.py" readme.md --cover --header --footer
python "<技能目录>/md2docx.py" readme.md --numbering --pdf
python "<技能目录>/md2docx.py" readme.md -o report.docx --cover --numbering --header --footer --pdf
```

## 功能说明

1. **文档头部**：开头的 YAML front matter（以 `---` 包围且内含 `key:` 行）直接剥离，不会当成正文或标题；不像 front matter 的 `---` 仍按分隔线/标题处理
2. **自动封面**（--cover）：取第一个 h1 作为标题，生成含标题/副标题/日期/装饰条的封面页，后接自动目录（TOC 域，Word 中右键更新域生效）
3. **标题编号**（--numbering）：格式为 `1、` / `1.1` / `1.1.1`。如果 Markdown 原文标题已包含编号（如 `1. 第一章`、`一、概述` 等）自动跳过不叠加；纯数字加空格的写法（如 `1 背景`）需至少两处命中才计为手工编号，避免一个“12 个要点”就把全文编号关掉
4. **图片**：相对路径以输入 Markdown 所在目录为基准；支持 URL 编码的本地路径。居中显示，按页面/单元格可用宽度及页面高度等比缩小，不放大小图；下方自动生成“图1 标题”格式的图注。图片缺失或损坏时显示灰色占位文本，不占用图号
5. **表格**：允许省略首尾 `|`，分隔行的每个单元格至少一个 `-`（`-|-` 也算表格）；分隔行里的冒号决定列对齐（`:---` 左、`:---:` 中、`---:` 右），表头与数据单元格同步应用；单元格内的字面量管道符写成 `\|`；保留内联格式，按内容分配列宽，表后自动生成“表1 标题”格式的表号
6. **代码块**：支持反引号和波浪号围栏，也支持 4 空格或 Tab 缩进的代码块；闭合围栏须使用相同字符且长度不少于开围栏。通过单格表格实现整体灰底+四周边框，保留空行，语言标签显示在代码上方
7. **列表**：层级按父项缩进推导，2 空格与 4 空格两种缩进习惯都能得到正确深度，回退到浅层也按父项算；第 3 层起在 `List Bullet 3` 基础上自动补缩进，嵌套不会挤在同一位置
8. **引用块**：按块重新解析，块内的列表、代码、表格、嵌套引用都按原样保留，正文段落统一叠加楷体 + 浅灰底 + 左侧色条
9. **脚注**：文末统一生成“注释”附录；表格、引用、列表里的脚注引用同样生效，没有定义过的 `[^x]` 按字面文本输出
10. **PDF**（--pdf）：通过独立 WPS COM 实例调用 `ExportAsFixedFormat` 导出，导出前先更新域（目录/页码），完成或失败后均尝试关闭文档并退出实例
11. **内联格式**：正文、表格、引用、标题中保留粗体、斜体、删除线，星号与下划线两种写法都支持（`snake_case` 不会被误判）；`<br>`、行尾两个空格或反斜杠都转为换行；`<https://...>` 与 `mailto:` 自动转成可点击链接；链接保留目标地址，空标签链接（`[](url)`）以目标地址作为显示文本；行内代码按字面内容保留

## 脚本调用与错误处理

- 输入支持 UTF-8（含 BOM）；输出必须为 `.docx`，自动创建输出父目录，拒绝覆盖输入文件。
- 成功时退出码为 `0`；输入/参数错误或转换失败返回非零退出码。PDF 导出失败时，已生成的 DOCX 仍保留。
- 在 Python 中调用 `build_docx(blocks, footnotes, base_dir=...)` 时，通过 `base_dir` 指定图片根目录；省略则使用当前目录。每次构建均独立编号。
- 此脚本使用轻量解析器，支持上列语法，不是完整的 CommonMark/GFM 实现。
