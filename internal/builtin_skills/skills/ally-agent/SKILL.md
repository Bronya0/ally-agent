# Ally 快速使用手册

## 0. 定位

Ally 是一个面向本地项目的桌面 AI 编程助手，用对话完成读代码、改文件、跑命令、查资料、管任务。跨 Windows / macOS / Linux，GPL-3.0-only，作者 Bronya0。

它和「网页版 AI 聊天」最大的区别：Ally 有工作区概念，文件读写和命令执行都落在你选的目录里，改完能看 diff、跑校验、提交代码。

回答用户时的三条口径：

1. 先问清是「没配好」还是「不会用」。模型连不上、Key 错、代理不通占了一大半。
2. 涉及目录、文件、命令的回答，一定要提工作区边界。
3. 不要承诺它没有的能力（比如云端同步、团队协作、自动 PR）。

## 1. 界面骨架

```
顶栏：品牌标 | 工作区 Tab 栏（运行中有小圆点，× 可关） | 历史工作区 ▾ | + 添加工作区 | 临时工作区 | GitHub | 更新 | 窗口按钮
左栏：Agent / 知识库 / 技能 / MCP 服务 / 模型 / SSH 集群 / 任务中心 / Token 统计 / 人机对战 / 插件 / 设置
主区：消息流 + 计划面板 + 输入框（composer）+ 信息栏
右侧：可拉出的工作区文件树
```

左栏默认收起成图标，悬停出名称；底部双箭头展开后显示文字菜单、历史工作区、工作区会话列表和「SSH 授权」按钮，还能拖右边缘调宽度。

各面板不是弹窗，而是**在同一位置换页**：设置、技能、MCP、模型、SSH、插件、统计、对战都替掉聊天区，按 ESC 返回。

## 2. 首次上手四步

1. 从 GitHub Releases 下载对应平台安装包。macOS 未签名，先把 `Ally.app` 拖进 Applications，再双击 DMG 里的「免签名启动Ally.command」一次。
2. 启动后选一个项目目录作为工作区。
3. 左栏「模型」→「添加模型」配置提供商。
4. 直接说需求，例如「帮我看看这个项目怎么启动」。

### 模型怎么配

在「模型」面板点「添加模型」：

| 字段 | 说明 |
|---|---|
| 供应商快速配置 | 按内置目录自动填接口地址、接口格式、上下文上限，Key 仍要自己填 |
| Base URL | 提示原文「Base URL（无需 /v1）」，官方 Anthropic 填 `https://api.anthropic.com`，末尾别加 `/v1` |
| 接口格式 | OpenAI Chat Completions / OpenAI Responses / Anthropic Messages，以及兼容服务 |
| API Keys | 可多行，按顺序做故障切换 |
| 模型名 | 「拉取模型」自动拉列表，也可以「搜索选择，或直接输入自定义模型名」 |

配好点「测试连接」，再「保存修改」。

多 Key 的真实行为值得向用户解释清楚：第一个 Key 正常时始终用它，失败后自动切下一个；切换只发生在**模型还没开始输出**之前，同一个请求内不会换 Key。所以输入框上方可能同时出现「重试中 2/6」和「第 2/3 个 Key 失败」，看到这两行不要手动重发，先确认是不是整池 Key 都不可用。

模型是按工作区选的，不同项目可以用不同模型；也可以给单个模型设「思考强度」（auto / off / low / medium / high / xhigh / max），off 显示为「关闭思考」，提示原文「需模型支持，不支持的模型请保持自动」。

## 3. 工作区、Tab 与会话

- 顶栏每个 Tab 是一个工作区入口，Ctrl+T 用当前工作区新开一个 Tab；`+` 添加新工作区；「历史工作区」下拉最近 50 条。
- 「临时工作区」在系统临时目录建沙箱，关掉 Tab 就删，适合一次性试验。
- 一个 Tab 绑定一个会话身份。切会话只换展示，输入框草稿按会话分开存，不会串。
- 会话按工作区隔离。看不到历史先确认工作区对不对，界面会提示「当前工作区暂无历史会话；其他工作区还有 N 个（切换工作区后可见）」。
- 新建会话：Ctrl+N、输入栏 `+`、左栏会话区 `+`，或 `/new`。会话名自动取第一句提问的前 20 字，**没有手动重命名入口**。
- 删除会话：会话列表里按 Delete 或点删除。运行中或压缩中的会话不能删，会提示「会话运行中，不能删除」。
- 没有「会话归档」，代码里的「归档」指的是消息太多时「展开/收起早期消息」：默认只渲染最近 180 行，展开后 360 行。

## 4. 输入框（composer）怎么用

- Enter 发送，Shift+Enter 换行。输入框自动增高 2 到 10 行。
- 运行中再发消息不是排队开新轮，而是**注入当前这一轮**，等当前工具批次结束后并入模型上下文；此时不能带附件，提示「运行中暂不支持发送附件」。
- 停止：ESC，或在输入框里按 Ctrl/Cmd+C（有选中文字时不拦截）。
- 附件只能**粘贴**（截图或复制文件），没有上传按钮；一次最多 8 个；图片按压缩后 ≤5MB 才发给模型，文本 ≤200KB，超了只留元信息；视频音频不支持直发，提示「把文件放进工作区后 @ 引用」。
- 用户消息悬停可删除，动作是「删除此提问及之后的对话」，会同步清理模型上下文，不可恢复。没有「编辑后重发」。
- 回答下方悬停出统计行：时长、缓存命中率、输入输出 token、token/s，以及导出、复制总结、快捷消息三个按钮。

### `@` 引用文件

输入 `@` 打开「@ 文件和目录」菜单，支持 `@"带 空格 的路径"`，↑↓ 选择，Enter 或 Tab 确认，ESC 关闭。菜单加载时显示「索引中...」，无匹配显示「没有匹配路径」。

### `/` 斜杠命令

输入框为空时打 `/` 弹出「指令 N · 技能 M」菜单：

| 命令 | 作用 |
|---|---|
| `/new` | 新建会话，清空上下文 |
| `/skills` | 查看可用技能 |
| `/sessions` | 查看和切换历史会话 |
| `/init` | 分析项目并生成 AGENTS.md |
| `/note` | 保存长期记忆 |
| `/lesson` | 总结容易再踩的坑并更新 LESSONS.md |
| `/review` | 代码审查 |
| `/compact` | 压缩对话上下文，用摘要替换历史消息 |
| `/push` | 提交并推送 |

另外：`/<技能名>` 加载对应技能（菜单里会动态列出已启用的技能），`/switch <序号>` 切会话（不在菜单里），`//` 开头的文本按普通消息原样发送。

## 5. 功能面板

| 面板 | 打开方式 | 用途与关键操作 |
|---|---|---|
| 技能 | 左栏「技能」 | 按来源分项目 / 用户 / 内置；启用停用；「添加」技能（名称、描述、何时使用、内容），保存到用户级 `~/.agents/skills/` 或项目级；「市场」 |
| MCP 服务 | 左栏「MCP 服务」 | 列表与状态（已连接 / 连接中 / 连接失败 / 已停用）；传输 stdio、sse、Streamable HTTP；每个服务的工具可勾选注入；JSON 导入导出；保存即重连 |
| 插件 | 左栏「插件」 | 「导入插件」（选 zip）或「从目录安装」、启停、导出（可选是否带插件数据）、删除（可勾「同时删除插件自己保存的数据」）；启用的插件在左栏多一个自己的入口 |
| 任务中心 | 左栏「任务中心」或信息栏两个图标 | 「后台服务」看启动时间、退出码、累计输出、缓冲区预览、停止服务；「定时任务」看调度、下次运行、上次运行、运行次数、连续失败、最近输出 |
| SSH 集群 | 左栏「SSH 集群」 | 节点表：别名、地址、认证、用途、风险；认证三选一（本机免密 / SSH Agent、指定密钥文件、密码）；「测试」连通性；导入导出 |
| SSH 授权 | 左栏展开区或信息栏图标 | 勾选允许**当前工作区**模型访问的服务器，新节点默认没有授权 |
| Token 统计 | 左栏「Token 统计」 | 今日 / 近 7 日 / 本月；输入输出、请求数、缓存命中率、缓存写入、均次 Token；近 30 天每日柱状图、本月热力图、本月模型与工作区排行 |
| 工作区文件树 | 信息栏最右按钮 | 树 + 右键菜单（新建文件、新建目录、打开目录、复制相对路径、复制完整路径、属性、重命名、删除、刷新）；预览与编辑源码是预览器顶部的切换按钮，不在菜单里；支持多选、Ctrl+V 把系统文件粘贴进工作区；有未保存修改会提示 |
| Git 改动 | 信息栏 Git 区 | 左侧文件列表带 `+ ~ -` 统计，右侧逐文件 diff，「刷新」，过长会标「已截断」 |
| 设置 | 左栏「设置」 | 通用（外观、自定义提示词、允许访问内网地址、Git Bash 路径、工具执行并发度、LLM 请求重试次数、自动压缩阈值、字号、自动更新、开机自启、知识库根目录、背景图、页面显隐、自动代码校验）、高级、网络（代理）、安全围栏（只读说明，没有可配项）、API 服务、关于 |
| 人机对战 | 左栏「人机对战」 | 休息区小游戏，切走不销毁房间 |

设置里两个常被问到的项：

- **自动压缩阈值**：默认 60%，可调 20% 到 95%。上下文用量超过它就自动压缩。
- **知识库根目录**：设了之后，工作区指向该目录时会进入知识库模式，出现一个不能关闭的知识库 Tab；没初始化时输入框禁用，只剩「初始化知识库」。

## 6. 消息里的卡片

- **工具卡**：一行「状态图标 + 英文动词 + 工具名 + 参数摘要 + 耗时」。读是 `Reading`，改是 `Edited +12 -3`，跑命令是 `Ran (npm test)`，失败会写成 `Delete failed` 这种带动作的说法。点开看正文：命令输出带 ANSI 着色、新建文件给前几行预览、编辑给左右对照 diff、删除给逐路径成功失败。
- **读/搜合并卡**：连续的读文件、grep、列目录会折叠成「已读取 3 次 / 搜索 2 次 / 罗列 1 次」，避免刷屏。
- **子代理卡**：显示步数预算与上下文，形如 `3/12 步`、`上下文 24.1k`。
- **提问卡（ask）**：模型反问你时出现，多问题可翻页，选项带「推荐」，还能写自定义回答，底部「提交回答」。不回答这一轮就停在那里。
- **计划面板**：模型用 plan 报进度，面板按顺序列出步骤，`✓` 完成、`●` 进行中、`○` 未开始，头部显示「计划 done/total」，可折叠。

## 7. 安全与拦截

Ally **不要求你逐个批准工具调用**，靠下面三层替代审批：

1. 工作区围栏：写、删与命令都落在主工作区加会话级附加工作区之内（写工具另可写 Ally 自己的数据目录）。越界时文件工具报 `E_PATH_OUTSIDE` 并附一段「可写范围」，命令报「安全围栏已拦截：命令可能修改工作区外的受保护目标」。读取不受这条边界限制，只有密钥与凭据位置、系统目录、二进制和超大文件另有拦截。
2. 命令围栏：`rm`、`unlink`、`find -delete` 这类删除命令会被要求改用 `delete` 工具；`.git`、`.svn`、`.hg` 元数据一律不许写；密钥类路径（`~/.ssh`、`~/.aws`、Ally 自己的配置）连读都拦。
3. 远端 SSH 单独确认：覆盖远端已有文件、执行高危命令时会弹带「确认允许覆盖写入」「确认允许执行」的询问卡；未登记的裸 SSH 目标（直接给主机和路径）首次连接还要过一张连接卡，可选「允许并在当前工作区保持信任」。已登记到 SSH 集群的节点不弹连接卡，改由「SSH 授权」按工作区控制。

附加工作区是个常见问题：它只在当前会话有效，用来放行主工作区之外的目录，可以「＋ 添加目录」；运行中增删也会当轮生效。

## 8. 上下文与缓存

- 用量超过阈值自动压缩，压缩期间不能发消息；完成后提示「上下文已压缩：120k → 18k tokens」，历史被摘要替换。
- 压缩、系统提示词变化、工具清单变化都会让供应商侧前缀缓存重建，界面会提示「上下文前缀发生变化…供应商侧缓存已重建」。这一轮费用会明显变高，属于正常现象，不是 bug。
- 想手动压缩用 `/compact`，或点信息栏上下文用量里的「压缩上下文」「压缩教训」「更新图谱」。

## 10. 客服问题速查

| 用户说 | 回答方向 |
|---|---|
| 模型连不上 / 401 / 404 | 先看 Base URL 是否多写了 `/v1`；接口格式与地址是否匹配（Anthropic 用 Messages 格式）；Key 是否整池失效；代理是否拦住 |
| 一直重试、报多个 Key 失败 | 多 Key 只在输出前切换，说明整池不可用，检查 Key 余额、限流、地址 |
| 回答被截断 / 报上下文超限 | 用 `/compact` 压缩，或新建会话；也可调低自动压缩阈值让它更早触发 |
| 费用突然变高、缓存命中率掉到 0 | 前缀缓存被重建（压缩、改系统提示词、改工具），属正常，下一轮会重新积累 |
| 工具报 `E_PATH_OUTSIDE` 或「安全围栏已拦截」 | 目标路径在主工作区之外，把目录加进会话级附加工作区，或换到正确工作区 |
| 删除文件被拒 | 删文件要用 delete 工具，模型在命令里写 `rm` 会被拦 |
| 搜不到 `.git` 里的内容 | 内容搜索默认跳过 `.git` 这类点目录；写、删、用命令改元数据会被拦，但 `read` 直接读 `.git` 下的文件是允许的 |
| 会话列表是空的 | 会话按工作区隔离，先确认当前工作区 |
| 运行中切模型没用 | 运行中锁定模型与思考强度，本轮结束后才生效 |
| 图片没发出去 | 附件只能粘贴；压缩后超过 5MB 会明确提示未发送；文本上限 200KB；一次最多 8 个 |
| MCP 显示连接失败 | 看传输方式与命令路径，stdio 用的是白名单环境变量，别指望继承 shell 里导出的变量；保存后会重连 |
| 插件装了打不开 | 清单只认文档里的键，写了未知键导入就报错；id 重复会覆盖升级，数据保留 |
| SSH 连不上 | 认证三选一；本机免密优先用 `~/.ssh/config` 和默认私钥；新节点还要在「SSH 授权」里给工作区勾上 |
| 定时任务没跑 | 任务中心看下次运行时间、连续失败次数和最近错误；任务由模型用 `scheduled_task` 创建 |
| 后台服务输出不全 | 缓冲区只保留最新的部分，点「查看完整缓冲区」或「复制」拿全文 |
| Token 统计不准 / 为空 | 统计按请求累计，异步刷新；切今日 / 近 7 日 / 本月看口径 |
| 想让模型记住项目约定 | 用 `/init` 生成 AGENTS.md，或 `/note` 存长期记忆；教训用 `/lesson` 写进 LESSONS.md |

## 11. 能力边界（别向用户承诺）

- 写入、删除与命令都在工作区（加会话级附加工作区）之内，没有「随便改整台机器」这回事；读取可以出圈，但密钥与凭据位置仍会被拦。
- 没有会话重命名、没有会话归档、没有云端同步，配置与会话都在本机。
- 不自动创建 PR、不自动改远端仓库，只有 `/push` 这类明确指令才会提交推送。
- 插件代码跑在主页面上下文里，不是沙箱；安装时不弹权限确认，只该装可信插件。
- SSH 凭据以明文存在本机配置目录，导出的文件同样含明文。
- 自动代码校验默认全关，要在设置里逐语言打开，开了才会在改完文件后出「校验警告」（提示不是失败）。
