# Build Directory

This directory holds build assets for the Ally desktop application.

The structure is:

- `bin/` — Compiled binary output
- `darwin/` — macOS-specific files (Info.plist, icons)
- `windows/` — Windows-specific files (manifest, installer, icon)
- `appicon.png` — Application icon source

See [Wails build documentation](https://wails.io/docs/reference/project-config) for details.
