# Build Directory

This directory holds build assets for the Ally desktop application (Wails v3).

The structure is:

- `bin/` — Compiled binary output (generated by `wails3 build`)
- `darwin/` — macOS-specific files (Info.plist, icons, Taskfile)
- `windows/` — Windows-specific files (manifest, icon, Taskfile)
- `linux/` — Linux-specific files (Taskfile, nfpm, appimage)
- `docker/` — Cross-compilation Docker assets
- `appicon.png` — Application icon source (single source for `darwin/icons.icns` and `windows/icon.ico` via `wails3 generate icons`)
- `config.yml` — Wails v3 project configuration (product info, dev mode)
- `Taskfile.yml` — Shared wails3 build tasks (frontend build, bindings, icons)

See [Wails v3 build documentation](https://v3.wails.io) for details.

Ripgrep is prepared offline from the official archives in [`tools/ripgrep`](../tools/ripgrep/README.md) during local builds and release packaging. Upgrading it only requires replacing the archives. Linux releases cover x64 and arm64; macOS retains the universal DMG filename for existing automatic updaters.
